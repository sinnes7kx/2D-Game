# Ghost Girl — v1.5 Combat & Rose Seals (development build)

The original Godot 4 project reconstructed from the user's two v1.4.4 ZIP
parts. Open `project.godot`, let Godot import assets, then run F5.

**New:** buffered attack direction fix, 19 additional weaker foes in five
combat areas, rarer monster drops and genuinely scarce rare/unique rolls,
persistent rose-hook-operated gates and chest unlocks in Blackbrick Court and
Ashen Causeway. Existing saves remain in the same `user://` path.

**Scope:** This is a functional source update validated statically; an engine
F5 playtest remains necessary. Full 2048×1760 scythe/halberd directional
atlases were not included in either uploaded ZIP and are not fabricated.
See `docs/V15_COMBAT_AND_ROSE_SEALS.md` and `tests/validate_v15.py`.
