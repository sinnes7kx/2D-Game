# Original cardinal art polish

Source: the existing `GhostGirl2/assets/ghost/` individual PNGs, not generated character replacements. All 64 original idle and walking frames and 32 original combat_v14/attack_unarmed_light frames (front, back, left, right, 00–07) have been polished directly in place: 96 source PNGs. The latter are reused by the existing hook-free body installer, thrust animations, wand poses and cardinal guard sequences. Each remains 256×220 RGBA; alpha, upper 105 rows, protected upper hand regions, pose geometry and filename are unchanged. Only bounded interior luminance detail (at most six levels per RGB channel) was altered, preserving the original face and silhouettes. Each output was decoded and compared to its intended pixel data before commit. No diagonal PNG is changed.

Other cardinal poses retain the conservative runtime detail pass, now gated away from the head and protected upper hand areas. Already processed idle, walking and shared combat PNGs and walking in-betweens skip that shader pass. Existing directional playback, wrist guides, guard sequence and combat timing remain intact. This is a conservative image restoration, not a fully painted style match. Dedicated weapon-specific combat, jumping and dodging PNGs are not yet individually polished; no new painted parry poses are claimed. No generated candidate atlas is required. Godot runtime and visual parity remain unverified.

The reproducible offline PNG processor is `tools/cardinal_png_polish_v295.js`; it checks exact alpha, protected pixels and decoded output equality before returning image bytes. It does not generate new poses or alter animation or weapon anchor data.
