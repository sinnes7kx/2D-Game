# Original cardinal art polish

Source: the existing `GhostGirl2/assets/ghost/` individual PNGs, not generated character replacements. All 32 original idle frames (front, back, left, right, 00–07) have been polished directly in place. Each remains 256×220 RGBA; alpha, upper 105 rows, protected upper hand regions, pose geometry and filename are unchanged. Only bounded interior luminance detail (at most six levels per RGB channel) was altered, preserving the original face and silhouettes. Each output was decoded and compared to its intended pixel data before commit. No diagonal PNG is changed.

Other cardinal poses retain the conservative runtime detail pass, now gated away from the head and protected upper hand areas. Already processed idle PNGs skip that shader pass. Existing directional playback, wrist guides, guard sequence and combat timing remain intact. This is a conservative image restoration, not a fully painted style match. Walking and combat PNGs have not yet been individually polished; no new painted parry poses are claimed. No generated candidate atlas is required. Godot runtime and visual parity remain unverified.
