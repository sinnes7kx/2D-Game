# The Crypt & Garden: connected exploration

```
           [MOONWAKE CRYPT] ---------------- [MEMORIAL GALLERY]
               |                                    |
               |                                    | optional alternate exit
               |                                    |
               +------------- [WAKING GARDEN] -----+
                                 |      |   \
                                 |      |    \ (Moon Rose Key)
                              bridge  arbor   [CHAPEL / later Act I]
                                 |      |
                                 +------+  linked walking & hook loop
```

The crypt is an intentionally peaceful introduction: the Moon Rose Key can be collected but isn't necessary to get outside. The Garden, Arbor and Bridge are open exploration regions. The Chapel Gate remains the intended path forward into later Act I once the key is collected.

## Creative traversal

**Broken Rose Bridge:** from the eastern plaza, take the long walking route around the lower water, or aim with **F** at the silver rose across the broken central span (within 450 world pixels). The water obstacle uses a dedicated hook-traversal collision layer to allow a genuine shorter crossing while the rope is pulling her. You can also pull loose stones with **Q** or throw them with **R** from different positions.

**Rose Arbor:** walk around the walled central flower bed, inspect the mirrored paths, and try hook positions around the outer arcade. There is no single forced completion route.
